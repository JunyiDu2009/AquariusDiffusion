# AquariusDiffusion

**Native low-bit (NLT) diffusion models** — the weights live in the quantized space
from step 0, instead of being compressed after an fp16 pre-training run.
The family is organised **by domain** (`AquariusImage` · `AquariusVideo` · `AquariusVoice`);
from `AquariusTerimageExp` onward every model trains in the **binary** space `{−s, +s}`.

```
AquariusDiffusion/
├── AquariusImage/                        image diffusion
│   └── AquariusTerimageExp/              first experiment: native ternary T2I  <- released
│       ├── README.md / README_zh.md      model page (bilingual, full detail)
│       ├── code/ · docs/ · figures/      code, technical report (CN/EN), report figures
│       └── portable/ · text_encoder/ · VAE/   where the Release weight files go
├── AquariusVideo/                        video diffusion (planned)
└── AquariusVoice/                        voice / audio diffusion (planned)
```

## Models

| Model | Quantizer | Status |
|---|---|---|
| [**AquariusTerimageExp**](AquariusImage/AquariusTerimageExp/) | ternary `{−s, 0, +s}`, one fp16 scale per 128 weights + STE | **released** — 558,347,012 params in a single 152.99 MB file (2.192 bpw), bit-exact int4 fused-kernel runtime |

**Naming convention (from this repo onward):** models are named **by domain, not by
bit-width** — so there is no separate "Terimage / Binimage" pair. `AquariusTerimageExp`
is the family's **first experiment** and happens to be ternary; everything trained after
it is **binary** (`{−s, +s}`), and future image / video / voice models each get a plain
name under their own branch. (`AquariusBinimage`, the planned binary counterpart of the
first experiment, was never trained — the compute budget ran out, report §7.1.)

## Start here

- **Model page — how to run it:** [`AquariusImage/AquariusTerimageExp/README.md`](AquariusImage/AquariusTerimageExp/README.md)
- **Weights:** published in this repository's **Releases** (three files). The int4 runtime
  kernel is **rebuilt from the base-3 master at load time, for your device**, so no prebuilt
  CUDA-specific file is shipped.
- **Technical report** (CN/EN, PDF + Markdown): [`docs/`](AquariusImage/AquariusTerimageExp/docs/)
- **The honest result in one line:** native low-bit training and low-bit fused-kernel
  inference are verified feasible end-to-end on real hardware; at this data scale the
  model's **quality is below a usable release bar**, and the saturation evidence is
  documented rather than glossed over.
