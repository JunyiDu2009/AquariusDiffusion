## 1. 总目标与范围

### 1.1 一句话定义

> 训练一个 **0.1B 级 UNet 一步去噪器**：输入一张"带有一定噪声、但主体轮廓仍大致清晰"的图片，一次前向推理，输出对应的无噪原图。不做迭代，不做文本条件，不从纯噪声生成。

### 1.2 范围界定

- **本项目只训练这一个去噪器单体模型**，在 COCO 干净图上人工加噪构造训练对。
- DiT 实时接力（16B DiT 单帧预算用尽时把中间图交给本模型）是本模型的**应用背景**，作为后续工作（§9），不占用本计划的关键路径与验收标准。
- 交付物：**NVFP4 1 步模型 checkpoint（A1 原生免解包推理）+ Gradio 推理 Demo**。

### 1.3 输入输出定义（像素空间）

| 项 | 定义 |
|---|---|
| 输入 | 带噪 RGB 图，3 通道，归一化到 [-1, 1] |
| 输入条件 | 噪声强度 p（标量，经 timestep embedding 注入） |
| 输出 | 预测的无噪原图 x̂₀，3 通道，[-1, 1] |
| 推理 | 单次前向，无迭代 |
| 训练方式 | 直接回归：每步采 (x₀, p) 构造一个训练对，单次前向 + MSE/LPIPS。**训练与推理都是一步**，无迭代、无教师模型、无采样链 |
| 分辨率 | 全卷积结构，支持 256 / 384 / 512 及任意整数尺寸 |

### 2.2 离线预处理（重要，先做）

115K 张原图如果训练时实时解码 + 随机裁剪，IO 会成为瓶颈（COCO JPEG 480×640 量级）。**M1 第一步先做离线预处理**：

1. 按短边分桶（256 / 384 / 512），每张图随机裁剪 1 个对应尺寸正方形 patch；
2. 保存为 PNG（无损，避免 JPEG 二次压缩伪影干扰去噪任务）或 WebDataset tar 分片；
3. 存放到 E 盘（约 115K × 3 档 patch，预计 10–20GB，E 盘现余 43GB，够用；若紧张可只存 256+384 两档，512 档实时裁剪）。

### 2.3 多分辨率策略（沿用 v1.0）

| 档位 | 短边范围 | batch size | 采样占比 |
|---|---|---|---|
| 256×256 | ≤320 | 64 | 4/9 |
| 384×384 | 320–480 | 32 | 3/9 |
| 512×512 | >480 | 16 | 2/9 |

## 3. 任务形式化：加噪定义（v1.0 缺失，v1.1 补充）

### 3.1 噪声强度定义

定义噪声强度 p ∈ [1%, 50%] 为**噪声方差占比**：

```
x_p = √(1−p) · x₀ + √p · ε,   ε ~ N(0, I)
```

信噪比 SNR(dB) = 10·log₁₀((1−p)/p)：

| p | SNR | 主观状态 | 任务定位 |
|---|---|---|---|
| 1% | 20 dB | 轻微噪点 | 主任务区间下界 |
| 10% | 9.5 dB | 噪声明显、结构完整 | 主任务区间 |
| 30% | 3.7 dB | 轮廓清晰、细节受损 | 主任务区间上界 |
| 50% | 0 dB | 结构勉强可辨 | 极限拉伸档，允许画质明显下降 |

**主任务区间 1%–30%**（对应用户目标"带噪但轮廓大致清晰"）；**30%–50% 为极限档**，训练覆盖但验收标准放宽。

### 3.2 条件注入

p 经 sinusoidal embedding → 2 层 MLP → AdaGN 注入每个 ResBlock，让模型知道当前噪声水平。

## 4. 模型架构（~0.08B UNet，像素空间）

### 4.1 结构（修正版）

| 模块 | 配置 |
|---|---|
| 输入 | 3 通道（带噪 RGB），无 latent、无 VAE |
| 下采样 | 4 层：64 → 128 → 256 → 512，每层 2 个 ResBlock |
| 瓶颈 | 512 通道，2 个 ResBlock |
| 上采样 | 对称 4 层 + skip connection |
| 输出头 | 1×1 卷积输出 3 通道（直接预测 x₀） |
| 条件 | sinusoidal(p) → MLP → AdaGN |
| 参数量 | 约 60–80M（64-128-256-512 配置实测估算，v1.0 的 ~100M 偏乐观） |

**预测 x₀ 而非 ε**：本任务是一步映射，直接预测干净图。

### 4.2 注意力位置（v1.0 硬伤修复）

**Self-Attention 只允许放在下采样 ≥2 次之后的层级（空间 ≤64×64）**：

| 位置 | 空间尺寸（512² 输入） | 序列长 | 注意力矩阵(FP16) | 允许 |
|---|---|---|---|---|
| 第 1 层下采样后 | 256×256 | 65,536 | 8.6 GB | **禁止** |
| 第 2 层下采样后 | 128×128 | 16,384 | 537 MB | 禁止（浪费） |
| 第 3 层下采样后 | 64×64 | 4,096 | 33 MB | 允许 |
| 瓶颈 | 32×32 | 1,024 | 2 MB | 允许 |

其余层只用 ResBlock（卷积）。这是 SD 系 UNet 的标准做法，也是 8GB 显存下的硬约束。

### 4.3 损失函数

| 损失项 | 权重 | 说明 |
|---|---|---|
| MSE 重建 | 1.0 | ‖x̂₀ − x₀‖²，像素级约束 |
| LPIPS 感知 | 0.1 | 冻结 VGG16 特征距离（评估/感知用，不参与量化链路） |
| 对抗（可选） | 0.01 | PatchGAN，仅在 M7 画质增强阶段开启，前期关闭 |

## 5. 训练流程：渐进加噪课程

### 5.1 五个阶梯

| 阶梯 | p 区间 | 目标 | 切换条件 |
|---|---|---|---|
| Stage 0 | 1%–10% | 轻微去噪 | LPIPS 连续 3 次评估不再上升 |
| Stage 1 | 10%–20% | 中等噪声 | 同上 |
| Stage 2 | 20%–30% | 较高噪声 | 同上 |
| Stage 3 | 30%–40% | 高噪声 | 同上 |
| Stage 4 | 40%–50% | 极限档 | 同上 |

### 5.2 采样策略（v1.0 遗忘 bug 修复）

每个阶梯内，p 从 **[1%, 当前阶梯上限]** 均匀随机采样，而不是只在新区间采样。例：Stage 2 每步 p ~ U[1%, 30%]。防止模型升档后丢失低噪声能力（接力场景低噪声帧才是大多数）。

## 6. 评估指标（v1.0 指标混乱，v1.1 重写）

### 6.1 指标定义

| 指标 | 计算方式 | 角色 |
|---|---|---|
| **LPIPS**（Alex） | 去噪图 vs 原图感知距离 | **主门控 + 主验收** |
| **PSNR** | 像素级信噪比 | 主验收（辅助） |
| SSIM | 结构相似度 | 参考 |
| CLIP 图-图余弦 | 去噪图 vs 原图 CLIP 特征余弦相似度 | 语义抽检（预期 >0.90，低于此说明语义崩坏） |
| FID | val2017 全量分布距离 | 参考（去噪任务预期 <10） |

> v1.0 的"clip-ratio"已废除：图-图 CLIP 相似度对残余噪声不敏感，不适合当训练门控；图-文 CLIP-Score 与本任务（无文本条件）无关。

### 6.2 目标值（初版，M1 冒烟后按 FP16 基线实测校准）

| 噪声 p | LPIPS | PSNR | 说明 |
|---|---|---|---|
| 10% | ≤0.10 | ≥30 dB | 主区间 |
| 30% | ≤0.15 | ≥26 dB | 主区间上界 |
| 50% | ≤0.25 | ≥22 dB | 极限档，允许明显下降 |

NVFP4 模型（W4A4 QAT 后）预计掉点远小于任何二值化路线，通常接近 FP8/FP16 水平；目标值维持上表，若实测掉点 >0.02，优先检查块 scale 设置、激活量化配置与首层/输出头的精度保留（见 §8.2）。以上为**估计目标**，Stage 0 跑完 FP16 基线后必须用实测值重新校准，再决定后续阶段是否继续。

- 256² / batch64 前向+反向约 30–40ms/步（0.08B 模型、约 20 GFLOPs/样本量级估算）；

## 8. 渐进式量化（QAT）：FP16 → FP8 → NVFP4（终态）

量化过程与加噪课程**正交**：在每个加噪阶梯内逐级降精度，切换门控同为 LPIPS 平台期判断。

| 阶段 | 权重 | 激活 | 实现要点 |
|---|---|---|---|
| Q1 | FP16 | FP16 | 基线，从头训练 |
| Q2 | FP8 (E4M3) | FP16 | **模拟量化**（fake-quant + STE）：per-channel 权重 scale，per-tensor 激活 scale |
| Q3 | **NVFP4（E2M1）** | FP16（QAT 时 fake-quant 到 FP4/FP8） | **最终目标**：E2M1 + 每 16 权重一个 E4M3 块 scale + FP32 per-tensor scale；首层与输出头保留 FP8；QAT 用 torchao（fake-quant + STE），可选 NVIDIA ModelOpt scale learning 进一步优化块 scale |

### 8.1 关键经验（来自文献核对）

- **原生二值（W1A1）已放弃**，评估与理由存档于 §8.3；终态为 NVFP4，画质预期接近 FP8，远好于任何二值化路线；
- **不需要三值缓冲**：三值（DoReFa）原是二值化的过渡态，终态改为 NVFP4 后直接从 FP8 起步做 NVFP4 QAT 即可；
- 跨精度迁移：从高精度 best ckpt 加载 → NVFP4 fake-quant 包装 → 续训，学习率 ×0.1；
- NVFP4 QAT 要点：STE 反传；块 scale 可静态（MSE/absmax 初始化）也可学习（ModelOpt scale learning）；**EMA 在 fake-quant 之前对浮点权重做**；
- **A1 路线的 QAT 配置（已拍板）**：torchao NVFP4 QAT，`weight_dtype=nvfp4, activation_dtype=nvfp4, group_size=16`（W4A4，激活同步进 fake-quant，与推理配置严格一致）；若激活量化导致掉点超 §6.2 门控，应急退 W8A8（A2）或 W4A16（A3），并在 M5 记录原因；
- torchao 的 NVFP4 QAT 目前仅支持 Blackwell 及以上 GPU——本机 RTX 5060（sm_120）正好满足。

### 8.2 存储与推理格式：NVFP4 A1 原生免解包（确定路线）

**NVFP4 格式**：数据 E2M1（1 sign + 2 exp + 1 mantissa，共 15 个有效值：0, ±0.5, ±1, ±1.5, ±2, ±3, ±4, ±6）；每 16 个权重共享一个 FP8（E4M3）块 scale；另有 FP32 per-tensor scale 做整体归一化。有效约 4.5 bit/值。Blackwell 原生格式，torchao / NVIDIA ModelOpt / TensorRT 全链路支持（竞品 MXFP4 的 scale 为 2 的幂、块大小 32，量化误差较 NVFP4 高约 88%——NVIDIA 官方对比）。

**0.08B 模型体积**：FP16 ≈ 160MB → NVFP4 ≈ 45MB（数据 40MB + 块 scale 约 5MB）。

**精度保留策略**：首层卷积与输出头保留 FP8/BF16——E2M1 仅 8 个有效量级，动态范围大的层不适合（FLUX FP4 量化的同款做法）。

**设计原则：存储 = 计算（免解包）**。权重以压缩格式直接进 Tensor Core，块 scale 在 GEMM 外层逐块施加——不存在"解包成另一种精度"的开销。两个硬约束：① PyTorch 原生低精度 API（`torch._scaled_mm` / `torch._int_mm`）均为 GEMM 级，3×3 卷积需 im2col 展开——这是数据重排（内存 K² 倍，小模型可接受），不是解包；② `torch._scaled_mm` 要求两侧同精度，所以 A1 采用 **W4A4**：激活在推理时动态量化，与 QAT 配置严格一致。

**路线表（A1 已拍板为确定路线）**：

| 路线 | 配置 | 定位 |
|---|---|---|
| **A1 NVFP4 原生** | W4A4 | **确定路线**：im2col → torchao NVFP4 dispatch / `torch._scaled_mm`（BlockWise1x16）；激活运行时动态量化；完全免解包；FLUX FP4 同款架构；sm_120 硬件原生；45MB |
| A2 FP8 原生 | W8A8 | **应急路线**：仅当 M5 画质门控因激活量化失败时启用；质量几乎无损；80MB |
| A3 dequant BF16 | W4A16 | **对照基准 + fallback**：unpack → BF16 → 标准 conv；零 kernel 风险 |
| A4 TensorRT int8 | W8A8 | **部署选项**：int8 conv 是 TRT 最成熟路径，端侧部署首选；需 calibration 或 QAT |

**A1 实现要点**：
- 数据流：输入 BF16 → 逐层激活动态量化（absmax → FP4/FP8 + scale）→ im2col 展开（3×3 conv → GEMM）→ `torch._scaled_mm`（权重为离线准备好的 NVFP4 打包 + BlockWise1x16 swizzle 布局，运行时不拆包）→ 输出回 BF16 → 下一层；
- LayerNorm / AdaGN / skip connection / 注意力等非 matmul 部分保持 BF16（FLUX 同款混合精度策略）；
- 首层与输出头按精度保留策略走 FP8（A2 式 `torch._scaled_mm` 路径），主体卷积/线性层走 NVFP4；
- 权重侧：NVFP4 打包 + 块 scale（per-16 E4M3 + FP32 per-tensor）离线生成，按 BlockWise1x16 layout 重排后直接进 scaled_mm；
- M6 基准对照：同一 checkpoint 分别跑 A1 与 A3，输出延迟/显存/画质三项对照表；A1 达标（延迟 ≤5ms 且画质过 §6.2 门控）则定稿，否则记录回退理由。

**sm_120 软件栈注意事项**：TransformerEngine 2.15 的 fused NVFP4 路径在 sm_120 会崩（shared memory 预算与 sm_100 不同），且 sm_120 缺硬件 stochastic-rounding cast；可用路径为 torchao dispatch 或自建量化 kernel。本项目只做 QAT + 推理，影响有限，但要有预期。

**激活量化的画质边界**：W4A4（FP4 激活）FLUX 已在 transformer 上验证，但卷积特征图 outlier 更敏感；因此 M4 QAT 必须覆盖激活 fake-quant，M5 以 §6.2 门控判定；若激活 FP4 掉点不可接受，可把激活提到 FP8（权重仍 NVFP4 的混合配置，需同步调整 QAT 与推理配置并重新验证）。

**结论**：存储与交付格式定为 NVFP4；推理采用 **A1（W4A4 原生免解包）为确定路线**；A2 为画质门控失败时的应急路线，A3 为对照基准与 fallback，A4 为部署选项。

### 8.3 原生 1-bit 评估结论：放弃（存档）

终态改为 NVFP4 后，原生 1-bit（W1A1）路线**放弃**。存档评估结论，便于未来重启：

1. **硬件存在但无生态**：Turing+ Tensor Core 有 b1 WMMA/BMMA 指令（XOR 当乘法、POPC 当累加，tile m8n8k128），CUTLASS experimental 支持，但 cuBLAS/PyTorch 不暴露，sm_120 可用性未验证；
2. **画质风险大**：BiDM（NeurIPS 2024）证实 W1A1 去噪模型严重掉点，需 TBS+SPD 特殊结构补救；而 NVFP4 QAT 在扩散模型上已被 FLUX 验证可追近平 BF16；
3. **收益不匹配**：0.08B 模型 BF16 前向已 <2ms（预算 5ms），XNOR 的理论算力收益会被 kernel 启动、im2col、打包解包开销吃光；APNN 的 15–89× 加速不可外推到本场景。

**可复用资产**（若未来出现端侧 bitwise 硬需求，如 CiM/FPGA 部署）：BinaryML/XNOR-popcount-GEMM-PyTorch-CPU-CUDA（现成 PyTorch 扩展，真 XNOR+popcount）、Triton XNOR kernel、CUTLASS b1 BMMA。注意 gemlite 的"1-bit"是 dequant 式，不是 XNOR。重启顺序：bit-serial 模拟验证画质 → PyTorch XNOR 扩展原型 → CUTLASS。

## 9. 应用背景与后续工作（不在关键路径）

### 9.1 DiT 接力定位

本计划训练的 UNet 是核心资产。未来接入 16B DiT 实时接力时需要两步额外工作：

1. **域差距微调**：本计划用高斯加噪合成训练对，而 DiT 中途交出的中间图带模型特有的结构伪影，残差分布不是高斯。需要采集真实接力对（DiT 跑若干步 → 中间图 + 干净原图）做微调。采集本身不需要实时，本机可做（慢而已）；
2. **联调**：16B DiT FP16 权重 32GB，本机 8GB 无法加载，且单步去噪带宽耗时几十毫秒，30fps 联调与验收需数据中心卡。

### 9.2 可选画质增强（v1.0 DMD2 一节的修订）

v1.0 的"16→8→4→2→1 步 DMD2 蒸馏"已废除：本模型天生一步，没有多步可蒸。如需进一步提升 NVFP4 模型画质，两个正确选项：

- **选项 A（简单，推荐先试）**：M7 开启 PatchGAN 对抗微调（§4.3 已预留 0.01 权重），提升锐度；
- **选项 B（重型，仅当存在多步教师时）**：正规 DMD2 需要多步采样教师 + 冻结 real score + 可训练 fake score + GAN 判别器 + TTUR（fake score 更新频率 5×于生成器）。可用的教师候选：16B DiT 本身，或把自己的 FP16 去噪器改成多步去噪流程后自蒸馏。复杂度高，列为远期研究项。

## 10. 里程碑与验收（修订版）

| 阶段 | 任务 | 预计 | 交付物 |
|---|---|---|---|
| M1 | 离线数据预处理 + 冒烟（2–3K 子集，Stage 0） | ~5K 步 | 打通全管线；FP16 Stage 0 ckpt；实测速度/显存/指标基线 |
| M2 | FP16 全区间渐进加噪（Stage 0–4） | ~50K 步 | FP16 全噪声区间模型；按 §6.2 校准目标值 |
| M3 | FP8 模拟量化 QAT | ~30K 步 | FP8 ckpt |
| M4 | NVFP4 QAT（W4A4，torchao） | ~30K 步 | NVFP4 ckpt |
| M5 | NVFP4 验收锁定（LPIPS 峰值 + §6.2 门控） | ~50K 步 | **NVFP4 最佳 ckpt（核心交付）** |
| M6 | A1 原生推理实现 + 延迟基准（im2col + scaled_mm，与 A3 对照） | — | 免解包推理管线 + 延迟/显存/画质对照表 |
| M7 | （可选）PatchGAN 画质增强 | ~20K 步 | 增强版 NVFP4 ckpt |
| M8 | Gradio Demo | — | 可运行 Web 界面 |

### 验收标准

1. NVFP4 1 步模型在 val2017 上：10% 噪声 LPIPS ≤ 0.13 / PSNR ≥ 28 dB；30% 噪声 LPIPS ≤ 0.18 / PSNR ≥ 24 dB；50% 噪声 LPIPS ≤ 0.28（极限档）。NVFP4 QAT 后预期接近 FP16 基线，若实测掉点 >0.02 按 §8.2 精度保留策略排查；
2. CLIP 图-图余弦 > 0.90（语义未崩坏）；
3. 单张 256² 推理 ≤ 5ms（GPU；**以 A1 原生免解包路径为准实测**，A3 dequant 路线作对照，A1 达标则定稿，差距 >0.5ms 或画质不达标则按 §8.2 记录回退理由）；
4. Gradio Demo：选图 → 拖噪声滑块（实时预览加噪）→ 一键去噪 → 拖动分割线对比。

## 11. 技术栈

- 训练：PyTorch 2.x + timm 风格组件或 diffusers UNet2DModel 改造（去文本条件、像素空间、3 通道）；
- 量化 QAT：torchao（NVFP4 QAT 仅支持 Blackwell+，本机 sm_120 满足；FP8 QAT 同样支持）；
- 原生推理（A1，免解包）：im2col + `torch._scaled_mm`（NVFP4 BlockWise1x16，权重离线打包重排；激活运行时动态量化；首层/输出头走 FP8 路径）；对照/fallback 为 dequant→BF16 标准 conv；
- LPIPS：`lpips` 库（Alex backbone，冻结）；
- Demo：Gradio 4.x；
- 环境：本机系统 Python 3.13 或独立 venv，PyTorch 需支持 sm_120（CUDA 12.8+），torchao 需较新版本。
